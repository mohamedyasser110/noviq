# Old Version Archive

This directory contains files from the previous frontend version that have been
superseded by the Next.js 15 App Router migration.

## CSS Files

The following CSS files from `styles/` were part of the old "vibe coding" aesthetic
(glassmorphism, glow effects, rainbow gradients, floating orbs) and have been
archived here. They are no longer imported or used in the current build.

Archive date: 2026-09-26

- `a11y-pro.css` — Accessibility utilities
- `antigravity-futuristic.css` — Futuristic design elements
- `antigravity-touches.css` — Touch interaction styles
- `apple-controls.css` — Apple-style control elements
- `apple-materials.css` — Apple material design effects
- `apple-motion.css` — Apple-style motion animations
- `apple-type.css` — Apple-style typography
- `base.css` — Base/reset styles
- `cards-pro.css` — Advanced card layouts
- `components.css` — Component styles
- `corporate-polish.css` — Corporate styling
- `design-upgrade.css` — Design upgrade styles
- `forms.css` — Form element styles
- `glass.css` — Glassmorphism effects (replaced by MD3 surfaces in globals.css)
- `hero-capability.css` — Hero section capabilities
- `hero-pro.css` — Hero section professional styles
- `image-prompt-builder.css` — Image prompt builder styles
- `interactive.css` — Interactive element styles
- `lang-toggle.css` — Language toggle styling
- `layout.css` — Layout styles
- `motion.css` — Animation/motion styles
- `resources.css` — Resources page styles
- `responsive.css` — Responsive design overrides
- `rtl.css` — RTL (right-to-left) support
- `sections.css` — Section styles
- `team.css` — Team page styles
- `theme-simple.css` — Simple theme
- `tokens.css` — Design tokens (replaced by MD3 tokens in globals.css)

## Current CSS

The only CSS file in active use is `styles/globals.css`, which consolidates all
MD3 design tokens, Tailwind configuration, and component styles into a single
file.
