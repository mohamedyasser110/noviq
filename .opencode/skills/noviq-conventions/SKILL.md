# Noviq Project Conventions

Two-folder structure: `frontend/` (static, no build step) + `backend/` (Express 5 + better-sqlite3, Node >= 18).

## Golden rules

1. **ALL API endpoints live in ONE file:** `backend/routes/index.js`, organized in numbered sections (1. Health ... 18. Admin content CRUD). NEVER create separate route module files — add new endpoints to the matching section in that single file. This is a deliberate deployment decision for shared hosting.
2. **Never replace `window.NOVIQ_CONTENT` with a new object.** `content.config.js` declares `const NOVIQ_CONTENT` (a global lexical binding that shadows the window property) and builders read the bare identifier. Language switching works by **in-place mutation** (delete keys + `Object.assign`) inside `applyLanguage()` in `frontend/js/engine/i18n.js`. Breaking this reintroduces the "stuck on English" bug.
3. **Every new user-facing string needs Arabic.** UI strings: add to `SPA_STRINGS` in `frontend/js/engine/i18n.js` and wrap with `t('...')`. Content/section data: mirror the key in `frontend/data/content.ar.js` (merged OVER English at runtime, missing keys fall back to English).
4. **PowerShell blocks `npm.ps1`** on this machine — always use `npm.cmd` in shell commands.

## Backend

- Start: `node index.js` in `backend/` — serves site + API + admin on **http://localhost:3001**
- Background server for testing: `$job = Start-Job -ScriptBlock { Set-Location 'C:\Downloads\Noviq\backend'; node index.js }; Start-Sleep -Seconds 4; ...; Stop-Job $job; Remove-Job $job -Force`
- Config: `backend/config.js` (env vars + `.env` fallback). `FRONTEND_DIR` defaults to `../frontend`. SMTP vars documented in `backend/.env.example`.
- DB schema: `backend/db/init.js` (tables: contacts, newsletter, assessments, consultations, solution_builds, content, users, password_resets, visits, chat_messages, admin_users, admin_sessions)
- Email: `backend/mailer.js` — `notifyNewLead()` (fire-and-forget) and `sendMail()` (awaitable). No-op unless `SMTP_HOST` is set; password-reset codes print to console in dev.
- Chatbot engine: `backend/chatbot/engine.js` (Levenshtein typo tolerance) + `knowledge.js` (intents/keywords AR+EN).
- Content flow: SQLite `content` table → `GET /data/content.config.js` (generated by `backend/content-store.js`) → `NOVIQ_CONTENT`. Admin edits English only.
- Rate limits: global 300/15min on `/api/`; auth 10/10min; admin login 5/10min; imagegen 10/5min.

## Frontend

- SPA with hash routes registered in `frontend/script.js` (`initSPARouter`); page renderers in `frontend/js/render/build-*.js`; new routes also need `PAGE_META` entries for SEO.
- Home sections built by `build-static.js` + `build-sections.js` from `NOVIQ_CONTENT`; reveal animations via IntersectionObserver (`.reveal` starts hidden).
- Language storage key: `localStorage['noviq_language']` = `'en' | 'ar'`.
- Icons: lucide (`createIcon(name, size)` helper, `data-lucide` attributes, call `lucide.createIcons()` after DOM injection).

## Admin panel

- Single self-contained file: `backend/admin/index.html` (inline CSS + JS) at `http://localhost:3001/admin` — credentials `admin` / `noviq2026`.
- Add a page: sidebar `<a data-page="X" onclick="showPage('X',this)">` → title in `titles` map in `showPage()` → `case` in `loadPage()` → `loadX()` function that sets `#page-content.innerHTML`.
- Authenticated calls via `apiFetch()` (Bearer token in `localStorage['noviq_admin_token']`, auto-logout on 401). Helpers: `esc()`, `fmtDate()`, `showToast()`, `openModal()`/`closeModal()`, `currentData` array for modals.
- Content editor whitelist: `OBJECT_KEYS`/`ARRAY_KEYS` in section 18 of `backend/routes/index.js` — new content keys must be added there.

## Verification

- Syntax: `node --check <file>` for every touched JS file (the syntax-guard plugin also does this automatically on edit).
- API smoke test: start server in a background job and `Invoke-RestMethod` the endpoints touched.
- Visual checks: use the `noviq-visual-check` skill.
